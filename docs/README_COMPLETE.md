## 🚀 Quick Start (3 Steps)

### 1. **Run the CLI:**
```bash
cd d:\Codes
run_cli.bat
```

### 2. **Try the Monitor:**
```
Press: M
See: Full system dashboard with RAM/CPU/Storage bars
Press: R (to refresh) or Enter (to go back)
```

### 3. **Run Some Code:**
```
Navigate to a Python/Java/JS file
Select [▶ Run]
Watch:
  - System status bar
  - Data flow visualization
  - Code execution
  - Performance report with graphs!
```

**That's it! You're ready! 🎉**

## 🐛 Troubleshooting

### **"Monitor not available":**
```bash
# psutil not installed
cd d:\Codes\python_portable\Scripts
.\pip.exe install psutil
```

### **Window too narrow:**
- Maximize the window
- Or resize to at least 100 characters wide
- Grid will show 1-2 columns on narrow windows

### **Code won't run:**
- Check if compiler/interpreter is installed
- Verify it's in system PATH
- Error messages will guide you
