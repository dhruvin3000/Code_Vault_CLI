## 🆘 Need Help?

### **CLI won't start:**
- Make sure you're in `D:\Codes\Code_Vault_CLI`
- Check if `python_portable` folder exists
- Try `.\python_portable\python.exe --version`

### **Monitor not working:**
- System monitor requires psutil (already included!)
- If missing: `.\python_portable\Scripts\pip.exe install psutil`

### **Can't run code:**
- Python/Java/Node.js must be installed separately
- Add them to system PATH
- CLI will guide you with installation links
