## 💡 Usage Examples

### **Example 1: Quick Code Run**
```
1. run_cli.bat
2. Type: 15  (Python_programs folder)
3. Type: 5   (Your script)
4. Type: 1   (Run)
→ Watch: Data flow + Execution + Report!
```

### **Example 2: System Check**
```
1. run_cli.bat
2. Press: M
→ See: Full system dashboard
3. Press: R (refresh anytime)
```

### **Example 3: Search & Run**
```
1. run_cli.bat
2. Press: S
3. Type: calculator
4. Type: 1 (first result)
5. Type: 1 (Run)
→ Watch: Monitored execution!
```
